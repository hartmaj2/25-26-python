Na začátku roku jsme začali úplnými základy Pythonu: vysvětlili jsme si, co je program, jak fungují příkazy print a input, co jsou proměnné, datové typy a běžné chyby v kódu. První větší část roku byla postavená na jednoduchých programech a hrách, například kreslení pomocí želvy, hazardní simulaci, práci se seznamy, inventáři a postupném vytváření jednoduchého programu s hrdinou. Důraz byl kladen na to, aby žáci pochopili základní programátorské konstrukce: podmínky, cykly, náhodná čísla, funkce a práci se vstupem od uživatele.

V průběhu roku jsme se několikrát přesunuli od čistého programování k praktičtějším a vizuálnějším projektům. Žáci si vyzkoušeli práci s vývojovým prostředím Godot, kde upravovali herní mapy, postavy a nepřátele. Později jsme pracovali také s knihovnou tkinter, pomocí které jsme vytvářeli jednoduché okenní aplikace, například klikací program nebo obchodnickou hru. Následně jsme přešli k pygame, kde jsme si ukázali tvorbu herního okna, zpracování událostí, vykreslování obrázků a pohyb postavičky. Tyto projekty byly důležité hlavně tím, že žákům ukázaly, jak se ze základních příkazů v Pythonu dá postupně vytvořit interaktivní hra nebo aplikace.

Významnou část kroužku tvořila také práce s microbbity a jednoduchými elektrickými obvody. Žáci si nejprve vyzkoušeli sestavení základních obvodů s LED diodami, tlačítky a baterií, poté používali microbit jako zdroj a řídicí jednotku. Programovali jsme blikání diod, práci s tlačítky, LED mřížkou, zvuky a rádiovou komunikací mezi microbity. Vznikly například semafory, jednoduché hry na LED mřížce a programy využívající náhodu. Tato část dobře propojila programování s fyzickým světem a ukázala, že kód nemusí existovat pouze na obrazovce.

Na jaře jsme se více věnovali webovým technologiím a internetu. Vysvětlili jsme si základní roli HTML, CSS a JavaScriptu, upravovali jsme existující webové stránky v prohlížeči a vytvořili jsme jednoduché vlastní stránky. Žáci si založili GitHub účty a zprovoznili GitHub Pages, aby mohli své weby publikovat na internetu. Vedle toho jsme probírali i praktické informatické koncepty: IP adresy, lokální síť, servery, cookies, ukládání dat v počítači, bajty, textové soubory a kódování znaků. Součástí byly i praktické ukázky, například jednoduchý Python server, chatovací server nebo server pro nahrávání souborů.

Celkově byl kroužek velmi pestrý. Nejvíce se osvědčily projekty, které měly jasný a zábavný výsledek: hazardní hra s ukázkou strategie Martingale, simulátor hrdiny, kvíz na hlavní města, Godot, práce s webem a některé části s pygame. Naopak některá témata byla pro část žáků náročnější nebo méně poutavá, například abstraktnější matematické úlohy, složitější práce s funkcemi, MakeCode u microbitu nebo některé okenní aplikace. Během roku bylo také vidět, že žáci se liší v samostatnosti: někteří aktivně vymýšleli vlastní řešení a rozšiřovali projekty, jiní potřebovali více vedení a konkrétnější úkoly.
