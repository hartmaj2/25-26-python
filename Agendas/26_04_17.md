## 1: Jak si vytvořit vlastní javascript hru a publishnout na internet

### Založení github účtu

- vytvořit si github účet (NA GITHUBU)

- vytvořit repozitář (TO UŽ MŮŽEME VE VSCODE)
  - ten slouží k verzování kódu
    - verze jsou užitečné, když něco pokazíme
    - můžeme se pak vracet do historie do doby, kdy to ještě fungovalo
  - zároveň můžeme mít svůj kód online a pracovat na něm odkudkoliv

- v settings repozitáře nastavit Pages -> Branch -> main (MUSÍME ZASE NA GITHUBU)
  - tím se uveřejní stránka na adrese: `https://jmeno_uctu.github.io/jmeno_repozitare/`

### Vytváření stránky

- na dně adresáře našeho repozitáře musí být soubor index.html
  - ten popisuje strukturu (kde je co) naší webové stránky
    - kde jsou nadpisy, odstavce, tlačítka atd.
  - to teoreticky už stačí
    - aby stránka vypadala hezky, tak se hodí mít nějaký styl, který se vytváří v jazyce .css
    - aby stránka uměla něco interaktivního dělat -> program (skript) v jazyce javascript

- abychom publishnuli (načetli změnu na internet), tak musíme nejprve kliknout na commit a poté na sync
  - než se změna projeví na webu, trvá to zhruba 40 sekund

## 2: Jak fungují webové stránky

- kostra stránky v jazyce html
- vizáž stránky v jazyce css
- interaktivní prvky v jazyce javascript
